# 账单 CSV 导入 · 自动分类记账

最小可用原型：把**微信支付 / 支付宝**导出的账单 CSV 拖进网页，按商户名自动归类，可手工改分类并导出。

> **重要**：本工具**不会、也无法**对接微信/支付宝支付接口自动拉流水。个人消费明细没有开放给第三方小程序的合法 API。只能使用你自己导出的 CSV。

## 怎么打开

在本目录启动一个静态服务器（推荐，样例按钮依赖相对路径）：

```bash
cd /workspace/expense-csv-import
python3 -m http.server 8765
# 或：npx --yes serve -p 8765 .
```

浏览器打开：http://127.0.0.1:8765/

也可直接用浏览器打开 `index.html`，但「加载样例」按钮在 `file://` 下可能被拦截，请改用手动选择 `samples/` 里的文件。

## 如何导出账单

### 微信支付

1. 打开微信 → **我** → **服务** → **钱包** → **账单**
2. 右上角 **···** → **导出账单**（或「下载账单」）
3. 选择时间范围 → 导出到邮箱 / 文件
4. 解压后得到 CSV（常见文件名含「微信支付账单」）
5. 拖到本页导入

路径可能随微信版本微调，以客户端实际菜单为准。

### 支付宝

1. 打开支付宝 → **我的** → **账单**
2. 右上角 **···** → **开具交易流水** / **导出**（文案因版本而异）
3. 选择时间与邮箱，下载邮件中的 CSV/Excel
4. 若是 Excel，请先另存为 **CSV UTF-8**
5. 拖到本页导入

## 样例文件

## 分类规则

编辑 `rules.js`：按关键词匹配「交易对方 + 商品」，**从上到下第一条命中**生效。未匹配 → **其他**。

默认类别：餐饮、交通、购物、日用、通讯、住房、转账、其他。

手工在表格里改过的分类会记在浏览器 `localStorage`，点「清除手工分类」可重置。

## 退款怎么算

状态含「已全额退款 / 交易关闭 / 退款成功」等会标成退款：

- **默认不计入支出/收入合计**（避免一笔花两次）
- 勾选「显示退款/关闭单」可在表格里看到

## 编码说明（UTF-8 / GBK）

- 近年微信导出多为 **UTF-8（可能带 BOM）**，本页会去掉 BOM。
- 若用旧版软件另存，可能是 **GBK**：页面会尝试自动用 GBK 再读一次；若仍乱码，请用记事本 / VS Code **另存为 UTF-8** 后再导入。
- 导出结果请用 UTF-8 CSV，避免金额列错位。

## 文件结构

```
expense-csv-import/
  index.html      # 页面
  styles.css      # 样式
  app.js          # 解析 / 汇总 / 表格
  rules.js        # 分类关键词（可改）
  samples/        # 演示 CSV
  README.md
```

零依赖，纯静态；不需要后端、不需要登录。

## 已知限制

1. 不支持直接读 `.xlsx`（请另存 CSV）。
2. 官方导出格式若大改表头，可能识别失败，需改 `app.js` 里列名映射。
3. 分类靠关键词，冷门商户会进「其他」，需补规则或手工改。
4. 数据只在本机内存 + localStorage，清浏览器数据会丢手工分类。
5. 不能替代有牌照的记账 App 做税务/对公审计。
