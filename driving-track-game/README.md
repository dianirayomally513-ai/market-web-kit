# 封闭赛道计时赛 · Demo

纯前端浏览器小游戏：第三人称俯视跟车、一圈计时、约 3000 kg 车辆手感。

## 怎么打开

1. 用浏览器直接打开本目录下的 `index.html`  
   - macOS：终端执行 `open index.html`，或把文件拖进 Chrome / Safari / Edge  
   - Windows：双击 `index.html`，或右键用浏览器打开  
   - Linux：`xdg-open index.html`
2. 也可在本目录起一个本地静态服务后再访问，例如：
   ```bash
   cd /workspace/driving-track-game
   python3 -m http.server 8765
   ```
   然后浏览器打开 `http://127.0.0.1:8765/`

无需安装依赖，无需联网。

## 操作

| 操作 | 键位 |
|------|------|
| 加速 | ↑ / W |
| 刹车 | ↓ / S / 空格 |
| 左转 | ← / A |
| 右转 | → / D |
| 开始 / 再来一局 | 界面按钮（开局也可用 Enter / 空格） |

手机浏览器会显示简易触控方向键。

## 玩法

- 封闭环形赛道，逆时针跑完一圈冲过黑白格子终点线。
- HUD 显示用时、罚时、速度；右下角有 **时速表**（指针 + km/h 数字）。
- 蹭到内外护栏：车辆轻微弹开，速度衰减，并加 **0.5 秒罚时**（无碎裂特效）。
- 完赛后显示总用时（含罚时），可再开一局。

## 物理说明（简化）

- 整备质量固定约 **3000 kg**。
- 加速：驱动力 / 质量，比轻车更「肉」。
- 制动：制动力随质量作用，车速越高刹停距离越长。
- 转向：高速时转向幅度受限，并保留侧向速度衰减（简化侧滑/惯性）。
